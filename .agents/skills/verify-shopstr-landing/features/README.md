# Shopstr verification map

Use the repository root and a completed `npm test` build. The browser helper owns its ephemeral server and isolated profiles. No database or credentials are required. Preserve proof after cleanup and report failures rather than treating skipped paths as passes.

- [Static content and navigation](content.md) covers seven public paths, aliases, contact/product links and no-JavaScript disclosures.
- [Hydration and delivery](hydration.md) covers root-node preservation, menu interactions, errors and unrelated page downloads.
- [HTTP and development](http-development.md) covers missing pages/assets, Markdown negotiation, public resources and HMR.
